# Research Copilot 五分钟演示

1. **项目与会话（30 秒）**：登录并切换项目，新建一段研究对话；说明项目、对话和单次运行之间的关系。
2. **联网论文检索（40 秒）**：选择“联网论文检索”，输入研究主题；展示公开学术来源候选，以及“搜索摘要尚未等同于原文证据”的边界提示。
3. **文件与证据问答（50 秒）**：展示 PDF/TXT/MD 的索引状态、版本和页预览；选择一份原文，用“资料证据问答”提问并打开页码、chunk 和原文摘录。
4. **Agent 与成果（60 秒）**：切换“单篇论文评议”或“多篇证据综述”；展示 Agent 读取来源、停止条件、MD/JSON/CSV 成果，以及需求修改后旧成果的 stale 标记。
5. **多轮状态与 Memory（40 秒）**：修改研究维度，说明 revision 如何防止旧结果覆盖；展示可编辑、可撤销的显式项目 Memory。
6. **失败恢复、Trace 与评测（55 秒）**：打开保留的失败运行，说明有限重试、fallback 与错误恢复；从 Agent 回答定位运行记录，展开模型、工具和校验 Span，查看费用并提交反馈。
7. **发布边界（25 秒）**：展示 Linux API/worker/db、备份恢复和镜像 digest。明确当前证据是本机发布候选；服务器部署、长期多人使用和生产 SLA 尚未发生。

工作方式共五种：研究对话，以及联网论文检索、资料证据问答、单篇论文评议、多篇证据综述四个任务 Skills。
